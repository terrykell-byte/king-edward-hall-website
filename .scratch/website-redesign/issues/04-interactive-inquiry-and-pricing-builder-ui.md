# 04: Interactive Inquiry & Pricing Builder UI

**What to build:** The end-to-end booking inquiry experience on the Room Hire page. Hirers select room, date/hours, guest count, and kitchen add-ons, view live price calculations, validate contact inputs, and submit structured booking inquiries.

**Blocked by:** 02: Three-Pillar Global Header & Navigation Shell, 03: Pure Pricing & Quote Calculation Engine

**Status:** ready-for-agent

- [x] Interactive step-by-step room selection (visual cards with capacity badges and photos)
- [x] Date picker, start time, and duration selector with real-time recalculation
- [x] Kitchen toggle add-ons (Main Kitchen / Jubilee Kitchen) updating total price immediately
- [x] Live quote summary card showing itemized breakdown (room rate, hours, kitchen charge, estimated total)
- [x] Contact details form with validation (Name, Email, Phone, Event Nature)
- [x] Submission generates a structured inquiry dispatch to `roomhire@kingedwardhall.org.uk` with user confirmation modal
